# Instruções do agente

## Fluxo de branches e pull requests

- Antes de reutilizar uma branch ou atualizar um PR, consulte o estado do PR no GitHub CLI.
- Se o PR associado já estiver `MERGED` ou fechado, crie uma nova branch a partir de `main` antes de implementar ou enviar novas alterações.
- Atualize um PR existente somente quando ele ainda estiver aberto e corresponder à alteração atual.
- Depois de validar os testes, envie as alterações pelo GitHub CLI e informe o link do PR.
